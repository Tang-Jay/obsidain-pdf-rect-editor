# PDF++ Region Editor 0.4.2

Prepared for the first public release of the local PDF region editor.

- Move and resize PDF++ rectangular selections from a preview dialog or the PDF viewer.
- Update the selected Markdown link while preserving its other parameters.
- Synchronize Excalidraw crop metadata, links, displayed dimensions and independent frames.
- Cancel adjustments and undo supported edits, with checks for concurrent source changes.

Desktop only; current UI language: Chinese. Enable PDF++ for in-viewer editing and Excalidraw for drawing integration. PDF originals are unchanged.

The declared minimum Obsidian version is 1.6.5; application-level compatibility testing is still pending. This is an independent companion to PDF++.

Install using the individual `main.js`, `manifest.json` and `styles.css` assets in the `pdf-rect-editor` plugin folder.
